# Dietary Restaurant Finder (AI App)

## Overview
A full-stack web application that helps users find restaurants based on dietary needs such as vegan, halal, and allergen-free options. (Note: This app is only a prototype.)

## Features
- User authentication
- Dietary filters
- Favorites system
- AI-generated restaurant summaries

## Tech Stack
- Glide AI (no-code platform)
- Database (Users, Restaurants, Favorites)
- AI integration for summaries
